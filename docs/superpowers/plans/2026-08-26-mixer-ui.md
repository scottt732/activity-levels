# Activity Levels — Plan 5: Mixer Landing Page

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A DAW-style landing tab — timeline (history + forecast) on top, a drill-down mixer of the current bus's channels with a MASTER strip in the middle, and a controls row for the selected strip at the bottom — that tunes the configured tree through the existing draft/Save flow and shows live levels; plus a minimal Patterns tab.

**Architecture:** Pure modules first (`timeseries.ts` scales/decimation/band geometry; `navigation.ts` mixer reducer; `fader.ts` log-scale math), each unit-tested; then Lit components (`al-fader`, `al-meter`, `al-strip`, `al-master-strip`, `al-mixer`, `al-timeline`, `al-strip-controls`, `al-patterns`) that consume the existing `Draft`/`store.ts` ops, `events.ts` factories, `al-override-field`, `al-envelope-sketch`, and the websocket API from Plan 4 (`activity_levels/timeseries`, `profile/*`, `simulation/log`, `state` with `real_value`, `next_wake`, `lights`). Timeline is hand-drawn SVG (no chart library). Selection (`Path`) is shared with the Groups tab.

**Tech Stack:** Lit 3, TypeScript strict, Vite lib build, vitest (jsdom), pnpm; HA `ha-*` components as in Plan 3.

**Spec:** `docs/superpowers/specs/2026-08-26-mixer-ui-design.md` (binding) + `2026-08-26-patterns-and-simulation-design.md` §9 (payloads). Handoff notes: `docs/superpowers/plan4-patterns-ledger.md` (forecast-day day types are provisional; cap `forecast_until`; `profile/get` ~1 MiB — cache; `lights` count in `state`).

**Interfaces:**
```ts
// api.ts
export interface TimeseriesQuery { group_id: string; start: number; end: number; resolution: "5m" | "1h"; include_children?: boolean; forecast_until?: number }
export const getTimeseries = (hass, q: TimeseriesQuery) => Promise<TimeseriesResponse>
export const getProfile = (hass) => Promise<ProfileState>
export const rebuildProfile = (hass, force = false) => Promise<{ rebuilt: boolean }>
export const getSimulationLog = (hass, group_id?: string, limit = 50) => Promise<SimulationLog>
export const callService = (hass, domain, service, data) => hass.callService(domain, service, data)

// timeseries.ts
export type Range = "24h" | "7d" | "30d"; export type Horizon = "off" | "24h" | "7d";
export const RANGE_SECONDS: Record<Range, number>; export const HORIZON_SECONDS: Record<Horizon, number>;
export function windowFor(now: number, range: Range, horizon: Horizon): { start: number; end: number; forecastUntil: number | undefined; resolution: "5m" | "1h" }
export function xScale(t0: number, t1: number, width: number): (t: number) => number
export function yScale(max: number, height: number, pad = 4): (v: number) => number
export function decimate(points: [number, number][], maxPoints: number): [number, number][]   // min/max bucket keeps peaks
export function pathFor(points: [number, number][], x, y): string                        // "M… L…"
export function bandPolygon(f: Forecast, x, y): string                                   // p75 forward, p25 back
export function forecastLine(f: Forecast, x, key: "p50"): [number, number][]
export function spanRects<T>(spans: [number, number | null, T][], x, t1: number): { x0: number; x1: number; tag: T }[]
export function nearestIndex(points: [number, number][], t: number): number             // binary search
export function cacheKey(q: TimeseriesQuery): string

// navigation.ts
export interface MixerNav { busPath: Path; selection: Path | null }
export type NavAction = { type: "open"; path: Path } | { type: "up" } | { type: "select"; path: Path | null } | { type: "arrow"; delta: 1 | -1; config: Config } | { type: "sync"; config: Config }
export function initialNav(config: Config): MixerNav          // busPath = ["groups", 0] (or [] when no groups), selection = busPath
export function channelPaths(config: Config, busPath: Path): Path[]   // stimuli first then children, in config order
export function reduce(nav: MixerNav, action: NavAction): MixerNav   // sync drops dangling paths; up = parent bus or no-op at root; arrow cycles channel strips + master (busPath itself)
export function breadcrumb(config: Config, busPath: Path): { path: Path; label: string }[]

// fader.ts
export const FADER_MIN = 0.1, FADER_MAX = 10;
export function toPosition(value: number): number       // 0..1, log scale, 1.0 → 0.5
export function fromPosition(pos: number): number      // inverse, rounded to 2 decimals
export function stepValue(value: number, dir: 1 | -1, fine = false): number   // ×1.05 (fine) or ×1.25, clamped
export function formatGain(value: number): string      // "1.00", "2.5"
```
